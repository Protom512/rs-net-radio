## 2025-02-02 - Colorized CLI Summaries
**Learning:** For CLI tools, a colorized summary provides a significant UX boost by creating a clear visual hierarchy and making success/failure states immediately identifiable. Using raw ANSI escape codes avoids adding new dependencies while maintaining high compatibility with modern terminals.
**Action:** Use ANSI escape codes (Green for success, Red for failure, Cyan/Bold for structure) to enhance the visual feedback of CLI operations.
